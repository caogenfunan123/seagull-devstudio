# 授权模型

Seagull DevStudio 的平台能力授权由壳侧 `AdbState.kt` 作为单一事实源，经 SharedPreferences（`dsh-adb`）live 键 + 环境注入传导到引擎与插件；同时支持 KernelSU root 直通通道。授权分两级：**引擎级（三道门）** 与 **会话级（档位门禁）**。

## 引擎级授权（设备侧权限）

| 门 | 内容 | 真值键 / 载体 | 说明 |
|---|---|---|---|
| 门 1 | All Files Access（全文件访问） | prefs `fullAccess`（live，壳 `syncFullAccess()` 写入）；env `DSH_ADB_FULLACCESS` 仅兜底 | 0.13.0 起 live 判定，重启即可见；不再依赖 env 重启生效 |
| 门 2 | 允许开关（授权总开关） | prefs `allowSwitch`（live） | 用户显式允许才谈得上配对/root |
| 门 3 | ADB 真实配对 | prefs `paired` + `pairPort`/`connectPort` | 内嵌 termux android-tools adb：`adb pair 127.0.0.1:<port> <code>` 握手（码值只进 argv，审计只记 codeLength） |

- `getAdbState()` 桥返回 `{tier, fullAccess, allowSwitch, paired, wirelessDebugOn, connected, authorized, message}`，前端授权页以此渲染。
- 壳自管常驻 adb server（`ensureAdbServer`：`server nodaemon` + 5037 真实 devices 往返就绪判定），配对/连接失败有分类归因（window-closed/protocol-fault/server-not-ready…）与 retry 自愈。

## KernelSU root 通道

- 探测 `/system/bin/su` 存在（`dsh-android-bridge` `detectRootChannel`）→ bridge 插件的 `currentStatus` 携带 `rootChannel` 信息位，`AdbAuthSection` 显示「已就绪（root 通道）」并隐藏配对表单。**root 通道不翻转 ADB 授权门**——ADB 工具在未配对时仍 fail-closed，root 能力走 root_ops 插件（su 提权）独立放行。
- `dsh-android-root-ops` 维护 root 保活：60s 心跳 `su -c id` 验证 uid=0；root 可用且应用不在 `/data/adb/ksu/.allowlist` 时自动写入（免弹窗持续授权），denylist 模式（MagiskSU 语义）回退写入 `.denylist`。
- 调用 su 用**干净环境**（清空 `LD_PRELOAD`，`PATH`/`LD_LIBRARY_PATH` 指向 /system），避免 termux-exec 钩子污染 root 子进程。

## 会话级授权（引擎内档位）

- 部署默认 `writeMode: workspace-write`（profile yml shell-termux config）；工具实际放行以**会话档位**为准——UI 档位选择器写入会话日志 `sandbox/mode` 事件（事件溯源，重启重放，两会话互不可见），`gateFor(session)` 实时 resolve 到 `sandboxPolicy`。
- 仅 `danger-full-access`（关闭沙盒/超级用户）档位注入 root 感知提示，`root_exec`/`device_ui_control`/`ubuntu_exec`/`apk_*` 等能力才向模型可见。
- ADB 能力（含观察类）仅 danger-full-access；自动审批不参与。

## 数据流

```mermaid
flowchart TB
    U[用户] --> UI[AdbAuthSection 前端]
    UI -->|setAdbPair/setAdbAllow 桥| P[壳 AdbState = 单一真值]
    P -->|syncFullAccess + live prefs| PREFS[(dsh-adb prefs)]
    PREFS -->|shellEnv env DSH_ADB_*| N[dsh 引擎 node]
    RK[/system/bin/su KernelSU 探测] --> BR[dsh-android-bridge]
    N --> BR
    BR -->|gateFor 会话级 resolve| TOOL[ADB/root/ubuntu/apk 工具]
    P -->|adb pair / adb server| A[设备 adb 守护]
```

写面唯一在壳侧原生 `AdbState`；桥/引擎/插件只读 live prefs。被提权方（agent 模型）不得自改授权。
